<task type="auto">
  <name>Task 1: CSP-Header in .htaccess ergänzen</name>
  <files>.htaccess</files>
  <action>Im bestehenden Block `<IfModule mod_headers.c>` (Zeilen 19–23, nach `Header always set Referrer-Policy ...`) eine neue Zeile ergänzen:

`Header always set Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval' https://unpkg.com https://heizreport.de; style-src 'self' 'unsafe-inline' https://heizreport.de; img-src 'self' data: https://heizreport.de; font-src 'self'; connect-src 'self' https://heizreport.de; frame-src https://heizreport.de; object-src 'none'; base-uri 'self'; form-action 'self'"`

Die Policy in EINER Zeile halten (Apache-Header-Direktiven sind einzeilig; keine Zeilenumbrüche innerhalb des Wertes). Bestehende Header (X-Content-Type-Options, X-Frame-Options, Referrer-Policy) unverändert lassen. Optional einen kurzen deutschen Kommentar darüber setzen (z. B. "# CSP: heizreport.de für Wärmepumpen-Check-Widget erlaubt"). Keine weiteren Direktiven hinzufügen — insbesondere kein `upgrade-insecure-requests` oder `frame-ancestors` (X-Frame-Options deckt Letzteres bereits ab).</action>
  <verify>
    <automated>grep -c "Content-Security-Policy" .htaccess | grep -q "^1$" && grep "Content-Security-Policy" .htaccess | grep -q "script-src 'self' 'unsafe-inline' 'unsafe-eval' https://unpkg.com https://heizreport.de" && grep "Content-Security-Policy" .htaccess | grep -qE "frame-src https://heizreport\.de" && echo OK</automated>
  </verify>
  <done>.htaccess enthält genau einen CSP-Header im mod_headers-Block; script-src, style-src, img-src, connect-src und frame-src erlauben heizreport.de; unpkg.com, 'unsafe-inline', 'unsafe-eval' und 'self' bleiben erhalten; die drei bestehenden Security-Header sind unverändert.</done>
